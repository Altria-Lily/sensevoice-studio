# 声刻 · SenseVoice Studio

一个完全在本机运行的音视频转写工作台。它使用 **FunASR + SenseVoiceSmall** 完成语音识别，使用 **FSMN-VAD** 切分时间段、**CAM++** 区分说话人，并可导出带时间轴的 TXT、SRT、VTT 和 JSON。

## 已实现

- 视频/音频拖拽上传，支持 MP4、MKV、MOV、AVI、WebM、MP3、WAV、FLAC、M4A、AAC、OGG、Opus 等常见格式
- 单文件最大 10 GB（10240 MiB），流式写入项目磁盘；显示实际上传百分比、已传大小、速度、预计剩余时间，支持取消未完成的上传
- 上传后分别显示音轨提取时长、各模型加载状态、已处理语音片段数、耗时与估算剩余时间；提供语言、说话人数、数字格式化和识别批次设置
- 自动提取 16 kHz 单声道音轨，无需手动安装 FFmpeg
- 普通话、粤语、英语、日语、韩语及自动语言检测
- VAD 语音切分、句级毫秒时间轴、CAM++ 说话人聚类
- 浏览器内播放，时间轴随音视频播放自动高亮；点击时间点可跳转
- 逐段编辑识别文字、重新指定说话人、将“SPK0”重命名为真实姓名
- 后台单队列执行，避免多个任务同时占满显存
- 任务和转写结果本地持久化，重启后仍可打开
- 完成后自动打开结果页，可切换“时间轴 / 全文阅读”；提供倍速播放与自动跟随开关
- 时间轴下滑自动翻页、上滑回看；虚拟滚动限制控件数量，跨段编辑与全文搜索仍覆盖完整结果
- 大视频与独立滚动文字双栏布局，支持“专注视频”、全屏、三档字号和播放定位；打开文字不会预加载大视频
- “外挂字幕”按钮支持当前转写字幕与本机 SRT / VTT 导入，可开关显示、调整时间偏移；转写字幕支持显示说话人，全屏同样可见
- TXT / SRT / WebVTT / JSON 下载，以及命令行批处理入口
- 模型延迟加载；第一次转写时下载，此后可以离线使用

## 工作原理

```text
视频 / 音频
    │
    ├─ imageio-ffmpeg ──► 16 kHz mono WAV
    │
    └─ FunASR AutoModel
          ├─ FSMN-VAD          语音片段与时间范围
          ├─ SenseVoiceSmall   文字、语言、情绪/事件标签
          ├─ CT-Transformer    标点恢复
          └─ CAM++             匿名说话人聚类
                    │
                    └─► 可校对时间轴 ──► TXT / SRT / VTT / JSON
```

说话人结果是匿名聚类标签，不是现实身份识别。你可以在结果页把 `SPK0`、`SPK1` 改为姓名，导出文件会使用修改后的名称。

## Windows 快速开始

推荐使用 Python 3.11。仓库自带的脚本会把虚拟环境、下载缓存和模型都放在当前 F 盘项目目录，避免占用系统盘。

### 1. 安装

在 PowerShell 中进入项目目录后运行：

```powershell
.\install.ps1
```

本机有 NVIDIA 显卡时，脚本默认安装 CUDA 12.8 版 PyTorch；没有 NVIDIA 显卡则自动安装 CPU 版。若只想使用 CPU：

```powershell
.\install.ps1 -Cpu
```

安装脚本默认使用清华 PyPI 镜像与南京大学 PyTorch 镜像；如果需要切回官方源：

```powershell
.\install.ps1 -OfficialSource
```

如果 PowerShell 阻止本地脚本：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

安装 PyTorch 和模型需要数 GB 磁盘空间。依赖只安装一次；模型要到第一次提交转写时才下载。

### 2. 启动

```powershell
.\start.ps1
```

然后打开 <http://127.0.0.1:8000>。也可以双击 `start.cmd`。

使用其他端口：

```powershell
.\start.ps1 -Port 7860
```

### 3. 使用

1. 拖入视频或音频。
2. 选择语言；不确定时保留“自动检测”。
3. 按需展开“更多设置”：已知人数可填 1–20，不确定时留空；显存紧张选择 15 秒批次。
4. 点击开始转写，先看上传字节进度，再看处理阶段进度；首次任务还需加载模型。
5. 在右侧时间轴上下滚动阅读，点击时间码播放校对；编辑文字或说话人名称后点“保存修改”。
6. 从右上角导出 SRT、VTT、TXT 或 JSON。

### 转写文字在哪里看？

- **当前任务**：完成后自动进入结果页；“时间轴”可按时间点播放和编辑，“全文阅读”可连续阅读和复制。
- **以前的任务**：首页下方“最近任务 · 查看文字”里点击“查看文本”，也可以直接“下载 TXT”。
- **本地文件**：默认保存在 `F:\FunASR_SenseVoice\data\jobs\<任务 ID>\`。新任务自动生成 `result.txt`（带时间与说话人）和 `result.json`（完整结构化结果）。较早的任务可能只有 JSON，仍可从页面下载 TXT，或保存一次修改生成本地 TXT。
- **校对之后**：点击“保存修改”才会更新本地结果和下载内容；页面会提示未保存的修改。

这里的“上传”是浏览器向本机服务传文件，不是上传到云端。上传期间不要刷新或关闭页面，未完成的传输不支持断点续传。上传完成后可以返回任务列表，但请保持后端服务运行。

上传进度来自浏览器实际发送的字节数。上传后的详细进度含义：

- **提取音轨**：FFmpeg 实际输出的音轨时长与媒体总时长；无法获得总时长时显示已处理时长，不编造百分比。
- **加载模型**：逐个显示 SenseVoice、VAD、标点与 CAM++ 的等待 / 加载 / 就绪状态和耗时。这里统计模型个数，不是权重文件的下载或读盘百分比；后续任务会复用已加载模型。
- **语音转文字**：VAD 确定分段后，按实际完成的 ASR 片段显示“已处理 X / Y 段”，并估算此环节剩余时间。批次可能按长度排序，累计处理时长不是“视频开头已连续转写到某分钟”。片段 100% 后可能仍需完成标点、全局说话人聚类和结果保存。
- 新进度需要重启后端生效；旧任务没有详细进度记录时保留兼容显示。API 的 `progress` 仍是流程概览，详细完成量在 `progress_details`，轮询可使用 `?include_transcript=false` 避免下载全文。

10 GB 是文件接收上限，不代表所有时长的视频都能在当前内存/显存下完成识别；请预留原视频、提取音轨及模型运行所需空间。单次模型加载、VAD 和最后的聚类可能没有中间回调，此时页面显示实际耗时与当前工作，不使用随时间自动增长的虚假进度。

### 长文本打开速度

时间轴改为**下滑自动翻页的连续滚动**，无需点击上一页 / 下一页。右侧文字区独立滚动，顶部显示当前位置，底部显示阅读进度与是否到达末尾。焦点在滚动区时可使用 PageDown / PageUp 或 Home / End；浏览器页内查找只覆盖已渲染内容，要查找整个视频请使用面板内的“搜索全部转写文字”。

只有可见区域及附近片段会创建编辑控件（上限 80 段，另保留至多一个正在输入的片段），离开屏幕的控件会回收，文字草稿保留在数据层。可变高度索引保留滚动位置，滚动、切换“全文阅读”、搜索和保存都不会丢失其他片段的修改。搜索、全文阅读、复制和导出覆盖完整结果，不只限屏幕中显示的片段；仍需点击“保存修改”才会写入本地文件。

桌面视频结果默认使用自适应等高双栏：根据窗口空间和播放器控件高度计算初始宽度，保留视频的 16:9 显示比例，让右侧文字卡片与视频卡片上下对齐。窗口宽度不足时以可用宽度为限，文字面板仍跟随视频卡片等高；展开外挂字幕设置时也会同步。音频结果保留适合阅读的文字区高度，手机与“专注视频”使用上下排列，不强制等高。

不再使用顶部按钮或滑块设置宽度。直接拖动两张卡片左右外侧的细边框即可调整页面宽度（960–1920 像素，不超过当前窗口可用宽度）；双击任一边框恢复自适应。边框获得键盘焦点后，左右方向键可调整，Shift 加速，Home / End 设为最窄 / 最宽，Enter 恢复自适应；拖动中按 Esc 可撤销。手动宽度在本机浏览器记住，旧版滑块宽度不会覆盖新版默认布局。首页保持原宽度不变，窄屏自动上下排列并隐藏拖动边框。拖动只调整页面与附近文字的排版，不重新读取视频或整份转写，也不丢失阅读位置和草稿。

说话人姓名收纳在文字面板内、阅读选项卡旁的“说话人设置”弹窗中，不占据页面顶部或视频下方空间。改名即时同步到时间轴及当前转写字幕；点击“完成设置”、关闭按钮或 Esc 会保留本页草稿，不会自动落盘。可在弹窗中点击“保存修改”，此操作与页面的保存按钮一致，会一并保存本页已修改的文字、片段说话人及姓名；保存失败会保留草稿并提示重试。

点击“专注视频”可将预览扩展到整行，每次进入默认按视频比例和窗口高度计算贴合画面的宽度；视频高度随宽度等比例变化，不再因固定高度产生两侧黑边，也不裁剪或拉伸画面。未开始播放时暂按 16:9 排版，读取到视频尺寸后自动适配，不会为调整布局提前加载大视频。专注模式仍可拖动外边框调整（桌面最小 640 像素，保留文字和控件空间），双击恢复贴合视频；此模式的手动宽度仅在本次专注期间有效，不覆盖双栏宽度，点击“恢复双栏”会回到之前的校对布局。视频文件画面中原有的黑边不会被自动裁掉。

也可直接全屏。平板和手机自动上下排列。字号支持标准 / 大 / 更大，视频模式、字号和播放设置会在本机浏览器记住。

开启“播放时跟随文字”后，文字会跟随正在播放的片段。手动用滚轮、触摸或滚动条阅读时会暂停跟随，避免打断校对；点击“回到播放位置”恢复。关闭跟随时仍可点击“定位播放”单次跳转。文件路径收纳在结果标题下的“查看文件位置”中，下载与保存入口仍在页面上方。

开发回归中，同一份 1995 段结果由旧版约 45 秒降低到约 0.32 秒可用（本机无头 Edge 测量，仅作性能参考）；新连续阅读器初次只渲染 17 段。12,000 段合成测试约 0.7 秒打开，并验证了上下滚动、拖动到末尾、跨段保存、全文搜索、全屏与手机布局。主要优化是有界渲染、批量计算文本框高度、避免全文生成逐条查找 DOM，以及延迟视频读取。

### 外挂字幕怎么使用？

1. 打开视频的转写结果，点击视频右上角的 **“外挂字幕”**，即可开启当前转写字幕，同时展开播放器下方的字幕设置。
2. 可取消“显示外挂字幕”，或点击“使用当前转写”恢复识别结果。选择转写字幕时，右侧校对文字与说话人改名会即时反映在预览中；仍需“保存修改”才会写入本地转写文件。
3. 点击“导入 SRT / VTT”选择电脑上的字幕文件。文件只在浏览器内读取，不上传到服务端或云端，不覆盖右侧转写内容，也不烧录或改写原视频。
4. 如果字幕快慢不一致，设置“时间偏移”：正数延后，负数提前，单位为秒，范围 ±3600 秒。更换来源会归零；此设置只影响当前预览，不改变字幕导出时间。

外部字幕上限 5 MB / 50,000 条（与视频的 10 GB 上传上限相互独立），支持 UTF-8、带 BOM 的 UTF-16，以及常见中文 GB18030/GBK 编码。无效文件会提示错误并保留原字幕；文件中部分无效字幕块会跳过并显示数量。暂时只导入文字与时间码，不应用外部字体、CSS、位置样式或特效；“显示说话人”开关仅用于当前转写字幕。

外挂文件和开关只用于当前页面，刷新或重新打开任务后需再次开启 / 导入。播放器使用[原生文字轨道](https://html.spec.whatwg.org/multipage/media.html#text-track-api)与 [WebVTT cue](https://w3c.github.io/webvtt/#the-vttcue-interface)，普通播放、专注视频及全屏使用同一字幕轨道。为避免长文本拖慢页面，只向播放器挂载当前时间附近的字幕，跳转时再更新，右侧时间轴依然可独立阅读。仅音频的结果页或无法播放视频而回退音轨时，不显示外挂字幕入口。

## 命令行批处理

Web 服务和 CLI 使用完全相同的识别核心。

```powershell
.\.venv\Scripts\python.exe -m app.cli ".\meeting.mp4" -o ".\output"
```

指定语言和格式：

```powershell
.\.venv\Scripts\python.exe -m app.cli ".\meeting.mp4" --language zh --formats srt txt json -o ".\output"
```

不区分说话人：

```powershell
.\.venv\Scripts\python.exe -m app.cli ".\voice.m4a" --no-speakers
```

## 配置

复制示例配置：

```powershell
Copy-Item .env.example .env
```

常用配置如下：

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `FUNASR_DEVICE` | `auto` | 自动使用 CUDA；也可指定 `cpu` 或 `cuda:0` |
| `FUNASR_MODEL` | `iic/SenseVoiceSmall` | ASR 模型 |
| `FUNASR_VAD_MODEL` | `fsmn-vad` | 语音活动检测 |
| `FUNASR_PUNC_MODEL` | `ct-punc` | 标点恢复 |
| `FUNASR_SPK_MODEL` | `cam++` | 说话人表征与聚类 |
| `FUNASR_MAX_SEGMENT_MS` | `30000` | 单个 VAD 片段最长毫秒数 |
| `FUNASR_BATCH_SIZE_S` | `60` | 推理批大小（秒） |
| `FUNASR_MAX_UPLOAD_MB` | `10240` | 单文件上传上限，10 × 1024³ 字节 |
| `FUNASR_JOB_WORKERS` | `1` | 后台并行任务数；GPU 场景建议保持 1 |
| `FUNASR_DATA_DIR` | `data` | 任务与结果目录 |
| `FUNASR_MODEL_DIR` | `data/models` | 模型缓存目录 |
| `FFMPEG_BINARY` | 自动发现 | 可选，自定义 `ffmpeg.exe` 路径 |

改完 `.env` 后重启服务。

## 输出格式

- **SRT**：每条字幕包含起止时间和 `[说话人]` 前缀，适合剪映、Premiere、DaVinci Resolve 等软件。
- **VTT**：使用 WebVTT voice cue，适合 HTML5 视频。
- **TXT**：适合阅读的 `[HH:MM:SS] 说话人：内容`。
- **JSON**：包含 `start_ms`、`end_ms`、`speaker`、`speaker_name`、语言、情绪和事件等结构化字段。

## 本地 API

启动后可访问 <http://127.0.0.1:8000/docs> 查看完整 OpenAPI 文档。

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| `GET` | `/api/health` | 检查 FunASR、FFmpeg、设备和模型状态 |
| `GET` | `/api/settings` | 实际上传上限、默认设置、保存目录及磁盘余量 |
| `POST` | `/api/jobs/upload?filename=...` | 原始二进制文件流上传；浏览器使用此接口，避免 multipart 临时副本 |
| `POST` | `/api/jobs` | 兼容 multipart 表单上传；大文件建议使用上述流式接口 |
| `GET` | `/api/jobs` | 最近任务 |
| `GET` | `/api/jobs/{id}` | 任务进度及转写结果 |
| `PATCH` | `/api/jobs/{id}/result` | 修改文本、说话人和显示名称 |
| `GET` | `/api/jobs/{id}/export/{format}` | 导出 `txt/srt/vtt/json` |
| `GET` | `/api/jobs/{id}/media` | 播放原媒体 |
| `GET` | `/api/jobs/{id}/audio` | 播放提取后的 WAV |
| `DELETE` | `/api/jobs/{id}` | 删除已结束任务及其本地文件 |

上传接口可传 `language`、`identify_speakers`、`use_itn`、`speaker_count`（可选 1–20）和 `batch_size_s`（可选 5–120 秒）。流式接口使用查询参数，旧接口使用表单字段。指定人数只是 CAM++ 聚类参考，不保证现实身份或多人重叠讲话的准确分离。

## 数据目录与隐私

- 原媒体、提取音轨和结果保存在 `data/jobs/<任务 ID>/`。
- 模型保存在 `data/models/`。
- 服务默认只监听 `127.0.0.1`，不会把媒体上传到云端。
- 删除任务会删除该任务目录中的原媒体、音轨和结果。

如果用 `-HostAddress 0.0.0.0` 暴露到局域网，请自行添加访问控制，不建议直接暴露到公网。

## 常见问题

### 显存不足

RTX 3060 6GB 通常可以运行这条流水线，但长音频或其他占用显存的程序可能导致 OOM。关闭其他 GPU 程序后重试，或在 `.env` 中设置：

```dotenv
FUNASR_DEVICE=cpu
```

### 浏览器不能播放 MKV

不同浏览器支持的封装格式不同。识别不受影响；界面会自动回退到提取出的 WAV 音轨，仍可按时间轴校对。

### 模型下载失败

确认可以访问 ModelScope，然后删除对应模型目录下未完成的临时下载并重试。不要删除整个 `data`，其中还保存着任务结果。

### 系统已有 FFmpeg

程序会优先使用 `FFMPEG_BINARY`，其次查找 PATH 中的 `ffmpeg`，最后使用 `imageio-ffmpeg` 随 wheel 提供的二进制文件。
